4 Códigos OBD-II (opcional)

Sepárelos con comas o espacios. Cada código tiene una letra y cuatro caracteres, por ejemplo P0300.

¿Qué significa cada código?
P
Tren motriz: motor, transmisión y emisiones.
C
Chasis: frenos, suspensión y dirección.
B
Carrocería: airbag, climatización y confort.
U
Red de comunicación entre módulos.

Si el segundo carácter es 0 el código es genérico (igual en todas las marcas); si es 1, 2 o 3 lo define el fabricante.
